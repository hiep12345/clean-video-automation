# Cấu hình Connectors (MCP) — Sales

## Công cụ tích hợp

### 1. CRM
- **HubSpot**: Tra cứu contacts, companies, deals, activities.
- **Salesforce**: Pipeline management, lead scoring.

### 2. 📧 Email
- **Gmail (MCP)**: Soạn/gửi email outreach, track replies.

### 3. 🔍 Nghiên cứu
- **LinkedIn (Web)**: Nghiên cứu prospects, company intel.
- **Crunchbase**: Thông tin funding, leadership, revenue.

### 4. 📝 Notes & Tasks
- **Notion (MCP)**: Lưu meeting notes, track action items.

---

## ⚙️ Hướng dẫn thiết lập
1. **HubSpot**: API key cần permissions: `contacts`, `deals`, `companies`.
2. **Gmail**: OAuth2 setup cho send/read permissions.
3. **Notion**: Database ID cho Sales Pipeline tracking.
