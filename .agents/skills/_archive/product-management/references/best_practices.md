# Tiêu chuẩn và Best Practices — Product Management

## 1. Feature Spec
- BẮT ĐẦU từ Problem Statement, KHÔNG từ solution.
- User Stories theo format: "As a [role], I want [action] so that [outcome]."
- Mỗi spec PHẢI có: success metrics, acceptance criteria, out-of-scope.

## 2. Roadmap
- Chia thành: Now (sprint hiện tại), Next (1-2 sprints), Later (quarter).
- Mỗi item có: owner, status, estimated effort.
- Review roadmap ít nhất 1 lần/month.

## 3. Sprint Planning
- Sprint goal = 1 câu rõ ràng.
- Capacity = team velocity × availability.
- Đừng commit quá 80% capacity (buffer cho bugs/interrupts).

## 4. Research Synthesis
- Cluster findings thành themes (affinity mapping).
- Phân biệt: observations (facts) vs. insights (interpretations).
- Mỗi insight có ≥ 3 supporting data points.
