# Cấu hình Connectors (MCP) — Product Management

## Công cụ tích hợp

### 1. 📋 Project Management
- **Jira**: Epics, stories, sprints, burndown charts.
- **Linear**: Issue tracking, cycles, roadmap.
- **Notion (MCP)**: PRDs, specs, meeting notes.

### 2. 📊 Analytics
- **Mixpanel**: User flows, funnels, retention.
- **Amplitude**: Product analytics, cohort analysis.
- **Google Analytics**: Web traffic, conversion tracking.

### 3. 🔬 User Research
- **Typeform**: Survey data collection.
- **Hotjar**: Heatmaps, session recordings.

---

## ⚙️ Hướng dẫn thiết lập
1. **Jira**: API token + project key.
2. **Linear**: API key với team permissions.
3. **Notion**: Database IDs cho PRDs, Roadmap.
