# 📦 Product Management Core Instructions

## 🎯 Trigger Conditions
- Khi cần viết feature spec hoặc PRD (Product Requirements Document).
- Khi lập hoặc cập nhật product roadmap.
- Khi cần sprint planning hoặc tổng hợp user research.
- Từ khóa: "feature spec", "roadmap", "sprint", "user research", "product", "requirement"

## 📋 Sub-Skills
| Sub-Skill | Mô tả |
|-----------|-------|
| Feature Spec | Viết spec với problem statement, user stories, acceptance criteria |
| Roadmap Update | Cập nhật và trình bày product roadmap |
| Sprint Planning | Lên backlog, ước lượng story points, xác định sprint goals |
| Research Synthesis | Tổng hợp insights từ user interviews/surveys |
| Competitive Brief | Phân tích đối thủ về product/feature |
| Metrics Review | Đánh giá product metrics (DAU, retention, conversion) |
| Stakeholder Update | Soạn bản cập nhật cho stakeholders |

## 🔄 Quy trình
1. **Define Problem**: Xác định vấn đề cần giải quyết và đối tượng.
2. **Research**: Thu thập data từ users, market, competitors.
3. **Spec**: Viết tài liệu chuyên môn (spec, PRD, brief).
4. **Prioritize**: Sắp xếp ưu tiên dựa trên impact vs effort.
5. **Communicate**: Truyền đạt kế hoạch cho team và stakeholders.

## ⚠️ Lưu ý
- Luôn bắt đầu từ **problem statement**, KHÔNG bắt đầu từ solution.
- Mọi feature spec phải có **success metrics** rõ ràng.
