# Cấu hình Connectors (MCP) — Human Resources

## Công cụ tích hợp

### 1. 👥 HRIS
- **BambooHR**: Employee data, org chart, PTO.
- **Workday**: Payroll, benefits, performance.
- **Gusto**: Payroll, compliance, onboarding.

### 2. 📋 Recruiting
- **Greenhouse**: Job postings, applicant tracking.
- **Lever**: Candidate pipeline, interview scheduling.

### 3. 📝 Documentation
- **Notion (MCP)**: Policy docs, onboarding checklists.
- **Google Drive**: Offer letters, handbooks.

---

## ⚙️ Hướng dẫn thiết lập
1. **BambooHR**: API key + subdomain.
2. **Greenhouse**: API key với job/candidate permissions.
