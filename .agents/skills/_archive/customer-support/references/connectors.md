# Cấu hình Connectors (MCP) — Customer Support

## Công cụ tích hợp

### 1. 🎫 Helpdesk
- **Zendesk**: Quản lý tickets, automations, macros.
- **Intercom**: Live chat, inbox, knowledge base.
- **Freshdesk**: Ticket management, SLA tracking.

### 2. 📧 Email
- **Gmail (MCP)**: Đọc/gửi email hỗ trợ khách hàng.

### 3. 📝 Knowledge Base
- **Notion (MCP)**: Lưu trữ và tra cứu KB articles.

### 4. 📊 Analytics
- **Mixpanel / Amplitude**: User behavior, feature usage.

---

## ⚙️ Hướng dẫn thiết lập
1. **Zendesk**: API token + subdomain cho ticket operations.
2. **Intercom**: Access token cho messaging APIs.
3. **Notion**: Database ID cho Knowledge Base.
