# Cấu hình Connectors (MCP) — SEO & AEO Engine

## Công cụ tích hợp

### 1. 🔍 SEO Tools
- **Google Search Console (API)**: Keywords, clicks, impressions, CTR.
- **Ahrefs / SEMrush (Web)**: Keyword research, backlinks, site audit.
- **Google Trends (Web)**: Search trend analysis.

### 2. 📊 Analytics
- **Google Analytics (GA4)**: Organic traffic, landing page performance.

### 3. 📝 Content Management
- **Notion (MCP)**: Content clusters, keyword maps.
- **WordPress (API)**: SEO meta tags, content publishing.

---

## ⚙️ Hướng dẫn thiết lập
1. **Google Search Console**: Service account với Search Console API enabled.
2. **Google Analytics**: GA4 API credentials.
