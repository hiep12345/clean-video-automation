# Tiêu chuẩn và Best Practices — SEO & AEO Engine

## 1. Keyword Research
- Phân loại intent: Informational, Navigational, Transactional, Commercial.
- Metrics: Volume, KD (Keyword Difficulty), CPC, SERP features.
- Long-tail keywords cho mới bắt đầu (KD < 30).

## 2. Content Clusters
- Pillar page → Cluster content → Internal links.
- Mỗi cluster 5-10 supporting articles.
- Semantic coverage: answer related questions.

## 3. On-Page SEO
- Title tag: Primary keyword + Modifier (< 60 chars).
- Meta description: Value proposition + CTA (< 155 chars).
- H1 unique per page, H2-H6 logical hierarchy.
- URL: short, descriptive, include keyword.

## 4. AEO (Answer Engine Optimization)
- Structure content cho Featured Snippets.
- FAQ schema markup.
- Concise answers (40-60 words) cho "People Also Ask".

## 5. Technical SEO
- Site speed: LCP < 2.5s, FID < 100ms, CLS < 0.1.
- Mobile-first indexing.
- Crawl budget optimization.
